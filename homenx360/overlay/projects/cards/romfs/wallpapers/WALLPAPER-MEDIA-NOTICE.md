# Wallpaper media notice

Xbox 360 and game artwork belongs to Microsoft and the respective publishers.
These media files are separate from the GPL software license.

The game theme images were preserved by Ashen Shore / thezodiaceffect in the
[Xbox 360 Themes Archive](https://archive.org/details/Xbox_360_Themes_Archivev.1).
Original bytes are retained; files named PNG by that archive whose bytes are
JPEG have been given the correct .jpg extension. Source checksums were checked.

The Night image is preserved in [StonedModder/Aurora-Coverflow-Layouts](https://github.com/StonedModder/Aurora-Coverflow-Layouts/tree/39fa0c7ffe55f0f111d7886245b297f18730ca8b/Aurora/User/Backgrounds).
The ring variants come from [riquenunes/pegasus-theme-npe](https://github.com/riquenunes/pegasus-theme-npe/tree/4c6c0d87e766f8f231e93507a94254447d3bebbe/assets/images/wallpapers).
No implementation code from either project is used. Community adaptations are
identified separately from original game theme images in SOURCES.json.

Microsoft's [NXE launch article](https://news.xbox.com/en-us/2008/11/19/top-10-things-to-do-when-you-get-the-new-xbox-experience/) confirms that Xbox 360, Spectrum, Day and Night were the original built-in
themes. This collection does not claim to reproduce all four complete themes.

SOURCES.json records the exact download URLs, revisions and SHA-256 hashes.
