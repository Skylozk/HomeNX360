# HomeNX360 original startup preview

Replaces the procedural HomeNX intro with the recorded original 2005–2010
Xbox 360 startup used during the NXE era. Includes all 288 frames at 30 fps,
losslessly encoded at Switch logical 1280×720, and the recorded startup sound.
No added logo, text overlay, recoloring, crop or custom fade. Background music
waits until the clip ends. A/B skips it and stops its sound. Returning HOME does
not replay it. The Animations and sound settings are respected.

Download `HomeNX360-preview.nro` to try first; read `INSTALL.md` before using
`HomeNX360-update.zip` with an existing HomeNX installation. The source archive
includes the original recording, conversion script, per-frame verification
report, code and upstream dependencies. Microsoft media is credited separately
from the GPL code.

Every converted frame was verified losslessly against resized source pixels.
Actual Switch performance, display matching and audiovisual latency have not
been tested on hardware. Playback follows a real-time clock and may drop frames
if decoding falls behind. Atmosphere 1.12.1 / system 22.5.0 remains unverified.
See `STARTUP-REFERENCES.md` for the inspected sources and fidelity limits.
